# 指标表（`metrics-table`）

把条目正文里的指标汇成**可读的对照表**：列统计、缺项提示、跨实验透视、CSV / Markdown 导出。

## 两个数据来源（默认都开）——**不需要你改写任何条目**

| 来源 | 说明 |
| --- | --- |
| **正文里的 Markdown 表格** | 只要一张表有「数值列」，它就按行变成记录。表头 = 指标名；**对象列自动识别**（第一个非数值列，如 `模型`/`方法`/`数据集`；`排名` 这种序数列会被跳过）；非数值列（如 `参数量出处`）作为附带信息保留 |
| **正文里的 ````metrics` 块** | 规范形式，最省事也最稳：`键: 值` 一行一项。适合还没有表格、想直接记几项指标的条目 |

````markdown
```metrics
mIoU: 0.732
Pd: 91%
```
````

> 设计说明：v1.0 只认 `metrics` 块，结果在**已有数据**上打开是一张空表——要求用户先改写正文才能看到价值，
> 那本身就是设计错误。现在**先读现有表格**；想规范化的条目再用写工具升级成块（可选）。

## 两种呈现方式

| 模式 | 长什么样 | 什么时候用 |
| --- | --- | --- |
| **按来源表分组**（默认） | 一张来源表 = 一个分组（表头 + 行 + 列统计），标题写清「哪条条目 · 哪个小节」 | 读你正文里的表：如 2.2 的「参数量与三数据集均值排行」9 模型 × 6 项 |
| **按对象透视** | 行 = 对象（同一模型/方法），列 = `指标@实验`，同一对象在不同实验的数字并到一行 | **跨实验对照**：同一个 DNANet 在 2.1 与 2.2 的 Fa/mIoU 并排看 |

配套控件：项目 / 类别筛选、关键词（同时过滤行与列）、「指标列最少出现」阈值、CSV / Markdown 导出（带 BOM，Excel 中文不乱码）。
点任意一行 → 显示它的**来源**（哪条条目、哪个小节、来自表格还是块）与该行全部指标——数字可追溯。

## 为什么不新增 kind

kind 矩阵是**内核契约**（`core/contracts/kinds.py` 是唯一声明处）：新增 kind 要同时改存放目录、标题前缀、
状态机、正文骨架、字段契约、索引与命名校验——那是"把功能搬进内核"。指标本质是**条目里的结构化内容**，
用正文表格/块表达就够：可搜索、可 diff、随条目一起进备份与报告，而且**任何 kind 的条目都能带**。

## 写入方式（安全边界）

**插件不直接改条目文件**。写只有一条路：

- Agent 工具 `p_metrics-table__record_metrics`（`spec.write = true`）→ 内核在 confirm 模式下**先生成草稿**，
  用户确认后才以 direct 模式调用本插件 handler → handler 走 `core_api.entry_update`（内核的校验写入路径：
  字段白名单取自 `core/contracts`、原子写、记 `doc_update` 活动）。
- 面板**不提供**"直接改条目"的按钮：它只读 + 导出 + 展示来源。
- 正文表格**本来就能被读到**，所以没有"必须先规范化"的负担；`mode=merge` 保留未提到的键，`replace` 整体覆盖，
  正文其余部分**逐字保留**；已有块未闭合时**拒绝写入**。

## 接口

| 路由 | 作用 |
| --- | --- |
| `GET table?project=&kind=&mode=records\|pivot` | `columns`（filled/missing/unit/min/max/mean）、`rows`（含 object/entry/scope/source/extra）、`sources`、`scanned`、`warnings`、`hint` |
| `GET entry?id=` | 单条条目提取出的记录 + 识别到的表格清单 + 正文预览 |
| `GET export?format=csv\|md&project=&kind=&mode=` | 下载 |
| `GET\|POST config` | 块名、来源开关（block/table）、默认类别、数值列阈值 |

Agent 工具：`p_metrics-table__metrics_table`（读，支持 `mode=pivot`）、`p_metrics-table__record_metrics`（写，走草稿闸门）。

## 边界（诚实的取舍）

- 只解析**确定性**结构：Markdown 表格与 `键: 值` 块。**不猜**散落在正文里的数字（如「Pd 0.7064 / mIoU 0.6912」
  这种行内表述）——猜错比不猜更糟。
- 序数列（`排名`/`编号`）不算指标；`—`/`-`/`N/A` 不算数值。
- 同一张表里若某列多数不是数字，该列不进指标列（作为附带信息保留）。
- 单次最多 600 条记录 / 400 条条目；`/api/docs` 之外的 kind 默认不扫（可在设置里放开 `scan_all_kinds`）。
