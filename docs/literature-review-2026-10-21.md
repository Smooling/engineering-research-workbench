# 统一文献工作区验收 · 2026-10-21

## 问题与实现

原绘制流程将未完成的 opaque canvas 放入 DOM，首次分配的黑底会在异步渲染期间出现；缩放与重新适应宽度还会先销毁现有画布。现在先在离屏画布填充白底并完成 PDF.js 绘制及文字几何提取，再一次性替换。缩放保留旧画布并调整 CSS 尺寸，过时的任务取消并由代际 / 记录标识隔离。缓存回收同时考虑尚未重绘的旧画布，避免缩放后积累；可见页与选区保持保护。PDF.js 3.11.174 及 worker 随包提供，禁止字体生成代码求值，附带 Apache 2.0 许可证。

文献路由直接打开统一 PDF 工作区；信息和笔记复用现有 Markdown 元数据与正文，没有创建另一份文献笔记。旧的无 PDF 元数据通过稳定的 `entry-<doc_id>` 适配记录显示，列表 GET 不改写这些记录；补传 PDF 时绑定相同文档和阅读记录 ID。既有文件、正文、引用和项目关联保留。元数据可编辑作者、项目、分类、标签、来源、日期、引用键、BibTeX、阅读状态和收藏；阅读位置更新不会为未改变的元数据重复产生文档写入。

BibTeX 独立存入 Markdown frontmatter。旧正文中的 BibTeX 仍可读取，并在首次写入时兼容保留为元数据；旧正文原样保留，除非用户自己编辑。替换笔记正文不会抹掉引用信息，更新 BibTeX 也不会向正文插入或修改代码块。真实临时文件测试覆盖这两种方向。

文献卡片使用一行题名和一行简要信息，支持分页、PDF 可用性筛选、当前页引用导出。左右面板均可拖动，支持键盘、双击复位和宽度持久化；窄屏资料栏使用浮层。修复了浮层继续使用零宽网格区域导致实际宽度为零的问题。

笔记编辑区与底部操作区分开布局，按钮不拆字；标签切换保留草稿，保存失败保留原输入，页面离开 / 退出接入原保存保护。保存接口可携带修订摘要，冲突时拒绝覆盖。Markdown 预览支持本地引用，编辑支持补全与插图。AI 整理显式使用最新笔记，不能被 PDF 选区替换；请求结果按文献与请求序号隔离，应用结果及添加批注先进入草稿，再由用户保存。

资料同步刷新仅更新列表，不重建阅读器，避免同步触发重绘。

## 验证方式

- `node tools/ui_usability_check.js --literature-only`：生成有 / 无 PDF 的旧资料，在渲染器刻意先绘制黑底、延时完成的情况下持续检查前台画布，确认初始及缩放期间没有黑色或未完成画布；验证旧帧保留、取消、左右拖动、键盘宽度调整、草稿保留、失败重试、保存确认、笔记 AI 的输入来源与应用流程、旧条目补传、信息字段、明暗主题与 2550 / 1920 / 1280 / 760 宽度及 125% 缩放。
- `--pdf-quality-only --pdf-fixture=Workspace/Knowledge/Literature/PDF/seed-2.pdf --pdf-page=7`：只读使用真实 PDF，运行真实 PDF.js，检查分页续读、清晰度、DPR 1 / 2 / 3、100% / 125% 缩放、400% PDF 缩放、缓存上限、回收恢复和渲染取消。
- `--references-only`：本地引用、预览、编辑补全、错误提示、稳定 ID 与跳转至统一文献工作区回归通过。
- 完整工作台浏览器回归通过，覆盖全屏 / 分屏、资料布局、里程碑、Agent、同步设置及原文档保存保护。
- 临时 Markdown / SQLite 测试覆盖无 PDF 条目展示、原位绑定后去重、元数据与正文保留、重复绑定拒绝、笔记修订冲突和后续更新。

界面接口使用模拟数据，真实 PDF 只读，后端测试使用临时工作区。AI 只使用模拟返回，没有实际模型或 Embedding 调用，不改动真实资料或个人配置。
