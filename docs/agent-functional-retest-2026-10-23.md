## 5.「本轮参考」重点核验

### 5.1 真实请求对照

独立测试服务记录到 152 次模型 HTTP 请求，来源存储中也记录到 152 次请求。对其中已登记的 217 个片段，逐项检查：

- 请求 messages 的摘要与实际 HTTP 内容一致。
- message_index、start/end 范围截取结果与 wire_text 逐字一致。
- 内部来源字段未发送给模型。
- 文本工具协议回退保留最终传输的偏移。

已记录片段的范围核对没有发现不一致。这个结论只证明记录的准确性，不证明覆盖完整；额外将 PDF/文件工具实际返回内容与来源列表对照，才发现 AG-01。

### 5.2 统计、历史与边界

- 搜索确实返回并发送 12 条、回答仅引用 3 条时，界面显示「12 条资料已提供 · 3 条在回答中引用」。
- 同条目搜索后读取合并为一张卡片，但保留不同快照和进入方式。
- 标题引用与内部 ID 引用可关联；同名、代码中的伪引用不错误计数。
- 修改原条目后，旧回答的快照不变化；打开原条目仍打开当前版本。
- 来源 GET 不重写会话投影，其他会话/外来来源/外来快照被拒绝。
- 审批后继续不重写暂停时的旧回答来源。
- 长文在不足预算时明确失败；使用足够预算及有界五步读取后完成压缩，六次模型请求保留节选/移除范围，实体计数仍为一条。
- 本地 MCP 未适配来源显示 incomplete；PDF/普通文件没有同等降级标记，是本次新发现。

### 5.3 宽屏实际浏览器检查

通过真实后端完成界面新建对话、发送、搜索/读取和回答，核对：

- 深浅主题、右侧并排面板、480px 面板宽度，无横向溢出。
- 切换来源时卡片与片段匹配。
- 点击复制后出现「片段已复制」；自动 UI 回归另检查复制内容。
- 原条目跳转及返回对话可用。
- 主页面和悬浮助手的同一会话回答一致；悬浮来源采用抽屉。
- 点击 AI 小球能从来源面板切回悬浮助手，关闭恢复正常。

## 6. 问题与修复优先级

### AG-01：部分资料读取漏记来源

真实合成 PDF 与文本文件分别经 `pdf_read`、`workspace_read` 成功读取，实际模型 HTTP 的工具消息包含各自唯一标记。然而来源接口返回 complete、0 个来源、无 warning；实际浏览器显示「本轮未提供知识资料」。

即使暂不实现这两种工具的精确快照，也应将覆盖标记为不完整。建议先修正降级判断，再补适配器，避免把「未采集」显示为「未提供」。

![PDF 已读取，但本轮参考错误显示零来源](retest-evidence-agent-2026-10-22/pdf-source-gap-wide.png)

### AG-02：自检入口与新参数不兼容

运行 `python tools/self_check.py`，在完成基础知识库、图谱、图片等检查后进入 Agent 校验时抛出：

```text
TypeError: main.<locals>.fake_http() got an unexpected keyword argument 'source_recorder'
```

这是测试替身签名落后于真实函数造成的自检回归，与 Agent 实际模型 HTTP 失败不同。建议同步替身签名，并重新运行完整自检，避免常用检查入口阻塞或漏测后续步骤。

## 7. 测试脚本误报复核

独立补充脚本首次运行出现的下列误报已保留原记录，并完成复核，不计为产品缺陷：

- Markdown 落盘自动补结尾换行；初始正文全等断言未去除换行。实际过期草稿已正确拒绝覆盖。
- 条目列表投影不包含全部排期字段；改查详情接口后确认开始日期、截止日期、进度均正确。
- 初始脚本未处理 failed 任务的 result=null，导致一组检查提前退出；补齐后继续验证。
- 归档 API 的契约字段为 id，初始脚本误用 session_id；按正确契约复核成功。
- 无状态合成模型按压缩后剩余 tool_calls 数判断进度，反复读取旧偏移并触发正常暂停。改用有界五步服务后，长文压缩正常完成。

原始记录、阶段复核及最终结果都存放在证据目录。最终问题仅依据实际读取与真实请求内容已确认的 AG-01，以及可直接复现的 AG-02。

## 8. 修复后建议验证

1. 为 `pdf_read`、`workspace_read` 增加准确来源适配，或至少在未适配时返回 incomplete。
2. 用真实工具注册名检查完整性分类；当前 `tool_message()` 内出现 `web_read`，实际注册名是 `web_fetch`，需一并审查其降级行为。本轮未访问公开网页进行端到端验证。
3. 增加「所有注册资料读取工具」的覆盖契约测试：必须产生来源块或明确的不完整标记；控制/写入工具单独分类。
4. 修正 self_check 的模拟 HTTP 签名并跑通后续检查。
5. 重跑 Agent 来源专项、两项失败补充场景、Agent 主/悬浮/任务结果 UI。
