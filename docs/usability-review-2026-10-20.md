## 后续调整：阅读空间与鼠标缩放

- 网页版笔记和 PDF 工作区按实际窗口分配高度，底部只保留正常边距，移除旧标题栏高度造成的空白；应用缩放为 125% 时也按折算后的可用高度布局。
- 笔记的精简信息在宽编辑区排成一行：标题、项目、状态、更多资料。较窄时排成两行；切换编辑模式不再自动展开所有元数据，其他字段仍可手动展开。
- Ctrl + 滚轮按鼠标位置动态缩放编辑栏、预览栏、资料列表、PDF 和 PDF 侧栏笔记，各自保持独立比例；普通滚轮继续滚动。保留比例选择作为备用入口，支持显示滚轮产生的非整档比例。
- 编辑与预览缩放保留阅读位置，缩放期间暂停两栏滚动联动，避免另一栏跳动；调整编辑字号后同步更新软换行位置映射，正文内容和光标不因缩放被修改。
- PDF 连续缩放先即时显示，再合并重绘；保留鼠标下的页内位置。适应宽度按实际内边距计算，并保留“适应宽度”恢复入口。

新增定向界面检查可通过 `node tools/ui_usability_check.js --reading-only` 运行：使用长笔记与内存 PDF 验证底部空间、信息区高度、各栏比例独立、编辑光标、PDF 定位及连续缩放的重绘次数，不调用真实模型或嵌入服务。

## 建议实施顺序

先处理“笔记 / PDF 阅读空间”和“默认能力 / 本次生效”的解释，再整理任务列表与 RAG 状态卡；之后改善资料的证据标签和图谱聚焦，最后调整概览与窄屏布局。每轮只改一个主要使用流程，用固定的长标题、长回答、空结果和失败场景复核，避免为了验证界面再次调用模型。

建议保留已有的优点：Agent 主页面与悬浮助手共享会话，长回答可追溯检索来源，历史问题编辑后保留原记录，危险操作有取消路径，后台索引构建时阻止并行清除。这些能力能减少重复操作和误操作。

## 全屏布局修复与验证

宽屏概览仍使用旧的 12 列外层网格，原有区域固定占用第 1～4 行，而新加入的统计开关与“继续上次工作”没有指定位置，被自动排到页面底部的单个窄格中。外层现改为按页面顺序逐行排列，各区域内部继续按宽度分栏；全屏、半屏、隐藏统计和空任务场景共用同一套顺序。

宽松模式另有规则将侧栏拉高到整页，导致粘性定位失效。现将侧栏限制在当前可用视口内，品牌与底部信息保持可见，导航列表独立滚动并阻止滚动传递到页面。高度考虑应用缩放和桌面标题栏，保留导航折叠、宽度调整与窄屏横向导航。

新增 `tools/ui_usability_check.js --overview-only` 专项检查，以用户截图对应的 2550 × 1233 全屏为首个尺寸，覆盖 2560 × 1440、1920 × 1080、1536 × 864、1280 × 720、1279 × 900、1100 × 800，分别检查两种密度和 100% / 125% 缩放，共 28 组组合；补充暗色空任务 / 空里程碑、隐藏统计、侧栏宽度模式及 760 像素窄屏。断言检查卡片顺序、区域全宽、重叠与横向溢出，以及页面和导航实际滚动后的侧栏位置。

原始错误已由新增断言复现；修复后专项检查、完整工作台界面回归及 Agent 界面回归通过。桌面模式另在 2550 × 1233、100% / 125% 下检查滚动时的侧栏偏移与高度。已查看全屏明暗主题和滚动截图。本轮仅更改前端布局，所有测试使用模拟接口，没有真实聊天或 Embedding 调用，没有更改真实资料、索引或用户设置。

## 项目标签与 PDF 清晰度

项目标签统一为 160 像素，普通标签为 120 像素，保持 22 像素的单行高度。长名称只在文字区域显示省略号，悬停可见完整名称，移除按钮保持可点。编辑器和 PDF 信息侧栏共用展示规则，保存和关联仍使用完整名称，字号至少为 11 像素。

PDF 原先仅按设备 DPI 绘制，普通屏幕为一倍像素，也未补偿应用界面的 CSS 缩放。现在以至少两倍显示像素绘制，高清屏按原生 DPI 绘制，并计入应用缩放；界面缩放、显示器 DPI 变化后自动更新画布。PDF 自身缩放完成后重新从源文件绘制，文字选择、批注和截图继续使用原来的页面坐标。

单页限制为 12 Mi 像素、单边不超过 8192 像素；保留按需加载和前后页缓存，并增加 40 Mi 像素的缓存目标，优先回收远离阅读位置的页面。可见页面、当前选区 / 批注页及正在绘制的页面不会强制回收，因此特殊情况下可临时超过缓存目标。过时的绘制任务会取消，已回收页面可在重新滚动到附近时恢复。真实 PDF 检查还复现并修复了续读页码被初始滚动事件重置的问题。

验证使用 `--pdf-quality-only` 检查长短项目名 / 标签、完整名称保留与删除、100% / 125% 缩放、DPR 1 / 2 / 3 变化、400% PDF 放大、连续翻页回收 / 恢复及绘制取消。另以真实 PDF 第 7 页和应用同版本的 PDF.js 检查全屏、放大和信息侧栏模式，等待画布完成后与 Poppler 页面图目视核对；原始文件只读。完整工作台和 Agent 界面回归同时覆盖原有选择、引用、滚轮缩放及保存保护；没有真实模型或 Embedding 请求。

- 笔记等文档预览中的本地引用，单击在右侧只读预览，Ctrl / ⌘ + 单击打开对应文档。大屏使用独立分栏，空间不足时改为浮层；可关闭、继续查看其中的引用并返回，并提供打开文档 / 阅读 PDF 的入口。预览保留正在编辑的原文和未保存状态，真正跳转时仍经过原来的保存保护。
- 编辑工具栏新增“引用”选择器，支持搜索标题或关键词；输入 `[[` 自动出现候选项，可用方向键、Enter / Tab、Esc 操作，也支持 Ctrl+Shift+K。中文输入法确认前不插入；插入后可撤销。引用自动使用稳定 ID 配合可读标题，保存仍保留完整关联，重名条目也能准确定位。
- 使用现有精确解析接口检查引用，找不到 / 已删除 / 同名歧义以红色波浪线标示，悬停显示原因，点击可重新检查。连接或服务异常显示为“暂时无法检查”，不会误报资料已删除。去重、短期缓存、限制并发，编辑或恢复资料后可重新检查。
- 仅处理本地双链、文档接口链接及本地 Markdown 路径；网络链接维持原有行为，代码里的双链示例不转为引用。候选搜索与文档列表的分页状态隔离，不使用 RAG、模型或 Embedding。HTML 先净化再转换引用。
