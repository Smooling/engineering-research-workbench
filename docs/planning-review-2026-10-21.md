# 图谱范围与里程碑计划验收 · 2026-10-21

图谱范围切换原先会调用 `focusInitialTopic`，自动挑选最近的笔记或首个文档，再把不在直接关系内的节点隐藏。现在初始化、切换范围和范围全览都保持未选中状态，关闭旧预览和搜索结果，取消旧相机动画并按范围布局自适应。相关标签保留，概况数量反映当前范围。这里的全览为已加载数据的范围全览，原有服务端加载上限与提示保留。

范围选择器固定宽度、长名称省略，展开后可搜索完整项目名，用方向键和 Enter 选择，Escape 关闭，Tab 离开。与甘特图共用组件；明暗主题一致。修复测试复现的组件内部移焦导致菜单立即关闭的问题。

甘特图是里程碑的一种视图，保留时间轴、列表和文档视图。阶段条表示明确填写的开始至截止，菱形表示仅有截止日期的节点；进度为用户填写，完成状态显示 100%。按首个项目分组，项目筛选会匹配所有关联项目，避免多项目条目重复计数。提供状态、逾期和未排期筛选、搜索、项目折叠、全览 / 日 / 周 / 月尺度和定位今天。名称列、日期表头固定，横纵滚动限制在图表内；侧栏编辑与原文档编辑器共享 Markdown，不新建另一套任务库。

日期与进度在服务端校验，非法保存不会覆盖原文档；清空开始日期会转为节点，清空截止日期转为待排期。旧数据缺失日期或存在日期错误时保留在表中。单独的计划快照接口读取全部里程碑的现有元数据，不受普通文档分页影响，也不返回正文。未保存的侧栏修改接入页面跳转、视图切换、刷新和桌面退出保护，失败保留输入。
