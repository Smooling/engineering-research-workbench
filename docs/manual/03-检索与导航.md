# 三、检索、导航与文件夹

## 1. 全局搜索（最快的一招）

**Ctrl/⌘ + K** 打开搜索框，输入任意词：

![全局搜索](img/global-search.png)

- **匹配范围**：标题、正文、标签、项目、分类标记，以及**待办**与 **Agent 对话**；
- **结果行为**：点一行直接跳到那条记录（文献跳文献、笔记跳笔记、待办跳待办页）；
- **引擎**：内核的中文全文索引（SQLite FTS + trigram 兜底），不是前端过滤——所以几万条也快；
- 搜索框下方的提示会写明本次命中来自哪些字段。

> 用不好搜索的常见原因是**条目标题没起好**。标题是检索权重最高的字段，命名规范（第二章第 4 节）不是形式主义。

## 2. 条目页内的筛选（在某一类里精找）

每个条目页（灵感 / 日志 / 笔记 / 实验 / 里程碑 / 总结 / 文献）左侧都是「搜索 + 筛选 + 列表」：

![笔记页](img/notes-list.png)

从上到下依次是：

1. **搜索框**：只搜这一类，输入即过滤（标题、正文、标签、项目、分类都匹配）；
2. **＋**：新建一条（见第二章）；
3. **状态** 下拉：只留某个状态（如只看「稳定」的笔记）；
4. **项目** 下拉：某个项目 / **未归属项目（通用基础）**；
5. **分类** 下拉：按 10 个标记过滤（如只看「⚒ 方法」）；
6. **标签** 输入框：**精确**按标签过滤（支持补全），旁边「仅未归属」勾选框；
7. **列表**：每张卡显示标题、状态、摘要、标记徽章、项目、日期；点开即编辑。

> 组合用法：`实验` 页 → 项目选「红外弱小目标检测」→ 状态选「完成」→ 得到"这个项目已完成的所有实验"。

## 3. 文件夹页：看真实的磁盘

侧栏「资源 → 文件夹」：

- 左侧是 `Workspace/` 的**真实目录树**（不是虚拟视图）：`Knowledge/`、`Projects/`、`System/`、`Resources/` 都在这里；
- 点文件可在右侧预览/打开；`打开 Workspace` 用系统文件管理器打开目录；
- **新建文件夹**：填相对路径即可创建（用于放数据、图、稿件）；
- 顶部有「重新扫描并迁移」：识别旧结构并迁移到标准骨架（首次升级后跑一次）。

## 4. 导航习惯

| 想干什么 | 去哪 |
| --- | --- |
| 今天该做什么 | **概览**（今日/待办/研究节律/项目推进）或 **待办** |
| 翻某类记录 | 对应条目页 + 筛选 |
| 看知识之间的关联 | **知识图谱**（插件提供，设置里启用即可） |
| 找文件 | **文件夹** |
| 全局找内容 | **Ctrl/⌘ + K** |
| 改行为与外观 | **设置** |

## 5. 本章常见问题

| 现象 | 处理 |
| --- | --- |
| 搜不到刚写的内容 | 保存了吗？搜索走索引，未保存的草稿不在库里；保存后立即能搜到 |
| 搜索结果里有看不懂的条目 | 点进去看类别与标签；多半是早期条目命名不统一，可改名（界面改名会同步交叉引用） |
| 文件夹页看不到某些目录 | 目录树只列 `Workspace/` 下的内容；`config/`、插件目录不在其中 |
| 想按日期找 | 日志/总结用「记录日期」，条目卡上也会显示；或直接用日期串搜索（如 `20261010`） |
