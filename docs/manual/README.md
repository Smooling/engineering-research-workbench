# 工程科研工作台 · 使用手册

> **在工作台里读**：侧栏「系统 → 使用手册」，一章一章翻，图直接显示。
> **在编辑器里读**：本目录的 Markdown（`docs/manual/*.md`）与 `img/` 截图。
>
> 本手册讲**内核功能**（知识库、检索、文献、Agent、项目/待办/日历/里程碑、设置与运维）
> 和**插件体系**（常用插件怎么用、自己怎么写一个插件）。
> 每个插件的细节仍以 `plugins/<id>/README.md` 为准；「设置 → 插件」里悬停插件卡片可看演示预览。

## 三十秒版本

1. **启动**：Windows 双击 `run.bat`（或 `python server.py`），浏览器开 `http://127.0.0.1:8765`。
2. **建项目**：概览 → 项目推进 → 新建项目 → 自动生成 Notes/Experiments/Data/Results/Figures/Manuscript/References。
3. **写条目**：侧栏「研究 · 知识」里选一类（笔记 / 实验 / 文献…）→ 点左上 **＋** → 改标题、写正文、按 **保存**。
4. **排计划**：待办页添加任务（可到分钟）→ 勾完成；日历页与顶栏角标随时看「逾期 / 今天」。
5. **让 AI 干活**：侧栏「Agent」→ 设好模型（设置 → Agent / LLM）→ 提问；要它改知识库时，它会**先出草稿**，你点确认才落盘。

> 三条铁律（后面反复用到）：
> **① `Workspace/` 里的 Markdown 是唯一事实来源**，界面、索引、图谱都是它的派生物；
> **② 条目命名是硬约束**，不合规会被工具直接拒绝写入；
> **③ 任何 AI 写操作都要你确认**（草稿闸门），没有"AI 背着你改数据"这回事。
