# Windows 桌面版

当前版本：`v261026.1`。

双击 `ResearchWorkbench.exe` 即可打开独立窗口。推荐 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime；普通使用无需安装 Python。若提示缺少运行环境，安装 [Microsoft 官方 WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)。

## 窗口与后台运行

- 顶层标题栏右侧依次为最小化、最大化 / 还原、关闭。最小化缩到 Windows 任务栏；最大化仅占用当前显示器工作区，保留系统任务栏。
- “设置 → 窗口 → 点击关闭按钮时”可选择“最小化到系统托盘，继续后台运行”或“退出应用”，保存后立即生效，重启后保留。默认隐藏到托盘，后台服务、编辑内容和进行中的任务继续保留；Alt+F4 遵循同一设置。
- 双击标题栏切换最大化 / 还原。拖动标题栏移动窗口，拖动四边或四角调整大小。窗口最外沿使用原生鼠标缩放，不受页面滚动条或网页缩放影响；最大化时隐藏缩放区域，保留 Windows 任务栏。
- 页面标题、日期、天气、主题、布局密度和缩放集中在顶层标题栏。最小化按钮左侧的刷新图标打开菜单，可选择重新加载配置与索引或快速重启；点击图标本身不会立即重启。
- 标题栏的主题按钮可切换浅色 / 暗色。关联 Markdown 导出使用固定尺寸弹窗，长内容在窗口内滚动，小屏自动适配可用空间。
- 暗色模式覆盖待办、里程碑时间轴与列表、Agent 对话、文献工作区；侧栏和知识分类标签保留各自颜色。PDF 纸张维持原文颜色，周边工具栏与阅读区使用暗色。
- 概览“近期节点”使用连续时间轴，圆环随列表滚动；临近节点带轻微环绕动效。“设置 → 界面 → 动画”关闭或 Windows 开启减少动态效果时，圆环保持静态。
- 设置页、右下角提示消息和确认弹窗统一跟随亮色 / 暗色主题。删除和完成待办使用工作台内的居中弹窗；离开未保存的 Markdown 或退出应用时，可选择“保存并继续 / 不保存 / 继续编辑”。保存失败会保留当前编辑内容。
- 新建文档首先是内存草稿，首次保存才生成本地 Markdown；未修改的模板在离开或退出时直接丢弃。标题、状态、分类、标签等修改也会触发保存提醒；改回原始内容后不再提醒。关闭到托盘会保留当前编辑页面。
- 概览的学业、条件和活跃目标进度条带间歇波光，活动柱带错开的高光。可通过界面动画设置关闭；隐藏到托盘后暂停。
- 文档、PDF 和 Agent 工作区利用窗口底部空间，各页面随可用窗口宽度铺满，不再在宽屏两侧保留居中空白。条目信息展开时完整显示所有字段，收起后保留完整的“展开”按钮；小窗口容纳不下内容时由整个编辑内容区滚动，信息区不设单独滚动条，保存操作保持可见。项目卡片统一高度，长名称和描述可悬停查看。
- 桌面专注 / 休息计时由后台时钟负责，切换页面、刷新页面或隐藏到托盘仍继续。到时在当前显示器右下角显示独立置顶提醒，保留至手动点击“知道了”或关闭按钮；点击“打开工作台”会消除提醒并恢复主窗口。提醒适配亮色 / 暗色，不抢占输入焦点；多个未确认的提醒合并显示数量。暂停或重置会停止相应计时，完全退出应用时关闭计时和提醒窗口。
- 点击托盘图标或右键选择“打开科研工作台”恢复窗口；重复启动 exe 也会唤回原窗口。同一数据目录仅运行一个桌面实例。
- 完全退出：托盘图标右键 → “退出”。有未保存的 Markdown 时会要求确认；取消退出会恢复窗口。
- 系统托盘不可用时退回任务栏最小化，避免窗口隐藏后无法找回。
- `ResearchWorkbench.exe --background` 启动后直接在托盘运行。需要登录后启动时，可把带此参数的快捷方式放到 `Win+R` → `shell:startup` 对应目录。

隐藏到托盘并不会释放 WebView 内存，因为它需要保留正在编辑的内容；后台运行也不意味着 Windows 休眠或关机后任务仍能执行。

## 客户端与服务器同步

服务器也需要更新到支持同步的版本，再启动 `python server.py`。frp 的转发目标仍是工作台 HTTP 端口。打开客户端“设置 → 同步”，填写服务器的工作台访问地址（IP + 端口或 HTTP / HTTPS 域名），点击“测试连接”，选择内容与方式并保存。

- **不同步**：默认选项，本机不主动连接服务器，标题栏隐藏同步按钮。
- **主动同步**：点击标题栏同步图标，双向上传 / 下载已保存的变化。
- **自动同步**：保存变化后自动同步，并按设置的间隔检查服务器；隐藏到托盘仍运行，完全退出应用后停止。

启用后，同步按钮在刷新按钮左侧，使用圆弧同步图标与矢量下拉箭头，展开时箭头旋转。冲突数量以紧凑徽标显示，亮暗主题分别配色。下拉菜单可查看状态、上次成功时间及变化清单，也可只检查服务器变化。`A` 表示新增，`M` 修改，`D` 删除，`↓` 服务器更新，`!` 两端冲突；文档列表也显示对应标识。网络断开时保留本地记录，恢复后自动模式会重试，主动模式需再次点击同步。

默认同步 Workspace 内的 Markdown、PDF / 图片 / 附件、项目、待办、文献索引与批注、科研热力图活动，以及通用设置、主题、密度、缩放和专注时长。Agent 对话记录可单独勾选。API 密钥、模型账号、本机监听地址与端口、Workspace 路径、窗口与托盘设置、缓存、索引及账单不会同步。服务器地址、同步模式与勾选范围也各自保存在本机。

科研热力图包含在“项目、待办、文献、批注与科研热力图”中，按活动记录合并，两端已有进度会保留原始日期，不会因反复同步重复计数。本次同步协议为 2：请同时更新客户端和服务器，再点击“立即同步”合并历史；原有 Workspace、活动日志与 `System/Sync/` 应保留。

附件应放在 Workspace 内；本机绝对路径指向的外部文件不在本版同步范围内，每个附件最大 512 MB。文件按内容校验，只传变化的内容；附件中断可续传。未修改的新建模板和未保存的编辑不会上传。正在编辑且尚未保存的文档，会暂缓应用服务器更新。

首次连接时，若两端已有同一条目的不同版本，会保留两端并提示冲突。点击变化清单中的“处理”，可比较本地、服务器与上次共同版本，选择保留本地、服务器、两份文件或手动合并 Markdown。不会按电脑时间直接覆盖另一端。处理期间若内容再次变化，会要求重新确认。

同步删除的文件移入各自的 `Workspace/System/Trash/Sync/`，旧文件内容校验副本与同步基线保存在 `Workspace/System/Sync/`。升级与重启应保留该目录；复制资料初始化另一台全新的工作台时，勿复制 `System/Sync/`，以便生成独立设备编号。

服务器网页直接编辑该服务器的资料，通常保持“不同步”即可作为接收端，无需反向填写客户端地址。本版按单人使用方案提供同步接口，不要求登录；能够访问工作台服务的人也能够访问这些接口。

## 数据位置与升级

这是便携版：默认读取 exe 同级的 `config/` 和 `Workspace/`。把 exe 放在当前项目根目录，会沿用现有配置和资料。也可使用 `ResearchWorkbench.exe --data-dir "D:\ResearchData"` 指定另一数据目录。

### 条目转换与浏览导航

条目编辑区右下角的“⋯ → 更改类型”支持灵感、笔记和工作总结互转，保留 ID、标题、正文、项目、标签和创建时间，引用与图谱同步更新；“类型变更记录”可查看历次转换。目标类型兼容的状态会保留，否则使用目标类型的默认状态。文献、里程碑与其他专用类型暂不支持转换。

顶部前进 / 后退按钮（Alt + ← / →）可返回刚才的条目与阅读位置，恢复筛选、分页和编辑 / 预览模式；文献支持恢复笔记标签与 PDF 阅读位置。离开未保存内容时仍会询问如何处理。

知识链接和列表条目停留片刻显示悬停卡片，提供项目、标签、更新时间和最多 5 行正文；带章节的链接优先显示对应段落。正文与列表不再显示整栏的原生缩放提示，Ctrl + 滚轮缩放继续可用。

### 统一文献阅读

点击“文献”直接进入 PDF 工作区。上传 PDF 建立文献，右侧“信息”维护题名、作者、项目、分类、标签、来源、日期、引用键和 BibTeX，“笔记”编辑原 Markdown 正文。旧文献与引用 ID 保留，没有 PDF 的旧条目可通过“待补充 PDF”筛选找到，选择后原位补传，历史笔记不会被替换。

左右两条竖线可拖动改变文献列表 / 资料侧栏宽度；方向键微调，双击恢复默认，宽度在本机记忆。窄窗口的资料侧栏以浮层显示。笔记支持 Ctrl+S、预览、引用与插图，操作按钮固定在底部；切换标签保留草稿，离开或退出前提示保存。AI 整理的结果先加入草稿，核对后点击“保存笔记”。

PDF 在后台画布完成绘制后再显示，缩放期间保留上一帧，随后从源文件重绘；PDF.js 与 worker 随客户端提供，阅读本地 PDF 无需访问 CDN。依赖许可证包含在 `web/vendor/pdfjs-LICENSE.txt` 打包资源中。

引用导出会优先使用信息栏中的 BibTeX，并显示导出条数与缺失清单；显式清空的引用不会从旧笔记中重新导出，全部缺失时不下载空文件。

### 里程碑计划

“里程碑 → 甘特图”将阶段计划和截止节点放在同一张图中：填写开始与截止日期显示阶段条，仅填写截止日期显示菱形节点。点击名称或图中标记，在侧栏修改日期、进度和状态；也可打开原里程碑文档修改，数据保存在同一份 Markdown 的 `start_date`、`due`、`progress` 字段。未设置进度时不会推算；完成状态按 100% 显示。

可按项目、关键词和状态筛选，支持项目折叠、全览、日 / 周 / 月缩放和定位今天。名称列和日期表头固定，时间轴内部滚动；没有截止日期或日期需要修正的旧条目也保留在表内。可在“设置 → 界面 → 里程碑默认视图”中选择甘特图。测试样例独立生成，不会写入个人 Workspace。

计划保存会校验包含排期与正文的修订号。其他窗口、同步或 Agent 修改过条目时，旧表单保留输入并提示冲突；可比较当前值，点击“载入当前值并合并我的修改”，核对后再次保存。“完成”和“已完成”采用同一完成语义，概览项目卡显示待完成节点数。

Agent 可以创建或更新阶段计划的开始日期、截止日期、进度、状态和项目。写入先生成可预览字段旧值与新值的草稿，确认后才进入甘特图；过期草稿不会覆盖新计划，未指定日期时保持待排期。

将 ZIP 解压到有写入权限的目录后再运行，不要直接在 ZIP 内或 `Program Files` 中启动。首次运行会初始化配置和 Workspace。窗口大小、最大化状态及关闭行为保存在 `window-state.json`；主题、缩放等偏好保存在 `.webview-profile/`；日志为 `workbench.log`。端口被占用时会使用可用端口，并将其记在 `desktop-service.json`，使重启后的界面偏好仍能恢复；修改服务监听地址或配置端口后会重新选择。

升级时先通过托盘退出，再替换 exe。发布 ZIP 仅包含程序、许可证和本说明，不包含任何个人资料、API Key 或聊天记录。浏览器版仍可通过 `run.bat` / `python server.py` 使用。

若构建时旧程序正在运行，新版会另存为同目录的 `ResearchWorkbench-Updated.exe`。先从托盘退出旧版再打开新版；同目录程序共用数据，旧版未退出时启动新版只会唤回原窗口。`run_client.bat` 会选择最近构建的 exe；ZIP 内仍统一命名为 `ResearchWorkbench.exe`。

## 从源码构建

安装 Windows x64 Python 3.11+，双击 `build_client.bat`。它在 `build/.venv` 安装固定版本的桌面依赖，生成：

- 项目根目录 `ResearchWorkbench.exe`；
- `dist/ResearchWorkbench-Windows-x64.zip`；
- `dist/windows-build.json`，记录版本、文件大小和 SHA-256；
- `build_client.log`，记录构建输出。

已有 `build/.venv` 时会直接复用；创建环境时也可通过环境变量 `ERW_BUILD_PYTHON` 指定 Python 路径。自动构建可执行 `build_client.bat --no-pause`。源码变更后须重新构建 exe。

日常更新不需要为了打包修改代码：拿到最新源码后，在项目根目录运行上述脚本即可。脚本依次检查隔离 Python 环境、安装或确认依赖、准备图标，并将 Python 程序、网页资源、内置技能和 Python 运行时打包成单个 exe，最后生成发布 ZIP 与校验清单。首次构建或依赖有变化时需要下载依赖；普通使用者直接运行生成的 exe，无需 Python。

修改 `app/`、`web/`、`client.py` 等程序源码后，需要重新构建并退出旧版再运行新版。修改 `config/` 中的设置或 `Workspace/` 中的资料不需要重新构建。`VERSION` 只用于区分发布版本，可在发布新版本时更新；它不是编译前必须手动修改的文件。若用 `python server.py` 运行源码版，可重启服务加载代码变化，无需生成 exe。

底层采用 [pywebview](https://pywebview.flowrl.com/api/) 与 [pystray](https://pystray.readthedocs.io/en/latest/usage.html)，由 WebView2 承载现有前端，本地 Python 服务负责数据处理。Windows 11 使用系统圆角和阴影；Windows 10 的圆角效果由系统能力决定。
